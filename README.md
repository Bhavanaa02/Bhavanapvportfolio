# Cybersecurity Portfolio Website

A personal portfolio website showcasing my background, cybersecurity projects,
technical skills, work experience, certifications, achievements, and technical interests.

The website was designed in Figma and developed using React and TypeScript,
with a focus on a clean, responsive, and interactive cybersecurity-themed interface.

## Running the Project Locally

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm

### 1. Clone the repository

git clone https://github.com/Bhavanaa02/YOUR-REPOSITORY-NAME.git


### 2. Navigate to the project directory


cd YOUR-REPOSITORY-NAME

### 3. Install dependencies

npm i


### 4. Start the development server

npm run dev

The development server will provide a local URL that can be opened
in your browser.

## Build for Production

To create a production build:

npm run build


## Preview the Production Build

npm run preview
